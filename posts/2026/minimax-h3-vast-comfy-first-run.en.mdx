## What I mean by handed down

This is a first-hand take, not a cost study, and not a claim that I was first.

A model with weights you can run yourself. A rented GPU. A visual workflow in ComfyUI. The pieces already existed. Putting them together and having the flow just work is the part that surprised me.

When that becomes smooth enough, and cheap enough, that anyone can play with it, the technology has been handed down. That is my opinion from one run. It is not a price chart.

## The service is great. The UI is not.

On 12 Nov 2026 I quoted that same post.

The Vast.ai service is great. But the UI is bad for my intent: using Claude Code from day 1.

Follow-up post: [https://x.com/Howard_Pengg/status/2120721244098363837](https://x.com/Howard_Pengg/status/2120721244098363837)

The rental layer did the job. The interface still is not built for showing up and running a coding agent on day one.

That does not undo the first point. The weights are reachable. The remaining friction is the product around them.
